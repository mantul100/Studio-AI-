Gemini & Google Sheets

Sesudah siap: operator hanya mengubah dropdown Setup

Masukkan Gemini API key dan URL Web App Apps Script yang terhubung ke Google Sheet. Key disimpan hanya di sessionStorage browser; URL webhook disimpan lokal. Setelah Setup siap, klik One Team Generate untuk memulai OTP.

Key tidak ditanam di HTML, project history, atau payload Sheet. Key dipakai oleh halaman browser untuk memanggil Gemini dan berada di memori/sessionStorage sesi ini. Jangan gunakan perangkat bersama; batasi key hanya ke Gemini API dan pantau kuota. Google kini menolak standard key yang unrestricted; key baru AI Studio dibuat sebagai authorization key. Jangan kirim key ke chat, source, atau log. Untuk penggunaan publik/produksi, jangan panggil API langsung dari browser—gunakan backend proxy.
Pilih model di sini; Tes API menampilkan model yang benar-benar dipakai. Jika model tidak tersedia, Studio mencari alternatif dan menampilkannya.
